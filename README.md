# Briareus Rust core

A shared core for the [Briareus](https://github.com/nadinyamaui/briareus) clients, written once in Rust and called from each native app:

| Client | Language | Binding |
| --- | --- | --- |
| [briareus-swift](https://github.com/okanetsolutions/briareus-swift) (Mac, iPhone, iPad) | Swift | UniFFI, as an XCFramework |
| [briareus-android](https://github.com/okanetsolutions/briareus-android) and [briareus-quest](https://github.com/okanetsolutions/briareus-quest) | Kotlin | UniFFI, as an AAR |
| [briareus-windows](https://github.com/okanetsolutions/briareus-windows) | C11 / Win32 | C header generated by cbindgen |

The core owns what every client implements today on its own: the `/api/v1` client, route catalog and token permissions, models, the event stream with resume and reconnection, the saved-response cache, incremental sync and the offline send queue. Each client keeps its native UI, secure storage, notifications, voice and web views.

Design tokens and the feature matrix stay in [briareus-contracts](https://github.com/okanetsolutions/briareus-contracts).
